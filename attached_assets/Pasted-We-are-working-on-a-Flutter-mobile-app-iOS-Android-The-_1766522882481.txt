Current problem

After successful login (non-Google), the home screen shows “Try again”

Search bar, categories, filters, item list, add-item UI, map, address fields are NOT visible

Root cause (confirmed)

ItemsScreen calls ItemsProvider.fetchItems() using latitude/longitude from LocationProvider

On first login, location is not yet available (latitude / longitude are null)

API call fails → provider error → UI collapses into “Try again”

Multiple features disappear together because they share the same provider state
